# Word Puzzle Center — Data Host

This repository is used as a **temporary data source for Word Puzzle Center games and applications**.

The files currently hosted here may be replaced, reorganized, or removed as we develop and compile our own original and properly sourced datasets.

## ⚠️ Temporary Data Notice

Some data currently available in this repository may have been obtained from third-party sources for **temporary development and testing purposes**.

If you are the creator, copyright holder, maintainer, or representative of any content or dataset included here and believe that your material has been used or hosted without appropriate permission, please contact us.

We will review the source and, where appropriate, **remove or replace the affected data promptly**.

Our long-term goal is to replace temporary third-party data with:

* Original datasets created by Word Puzzle Center
* Properly licensed datasets
* Public-domain or otherwise permitted data
* Data that we can legally redistribute and use in our puzzle games

## 📁 Repository Purpose

This repository primarily provides static data files used by our puzzle applications, such as:

* Word lists
* Dictionary data
* Puzzle data
* Category data
* Other supporting game data

The applications may load these files dynamically when needed.

## 🔄 Data May Change

Files in this repository should **not be considered permanent**.

Data may be:

* Updated
* Reorganized
* Replaced
* Removed
* Moved to another data source

Applications using this repository should therefore avoid relying on a particular file remaining permanently available unless explicitly documented.

## 📩 Data Concerns

If you recognize your work or data in this repository and would like us to review it, please contact us through the Word Puzzle Center project.

Please provide:

1. The file or data you are referring to
2. The original source, if applicable
3. Evidence of ownership or authorization, if relevant
4. Any preferred resolution

We will review legitimate requests and take appropriate action.

## 🎯 Long-Term Goal

Our goal is to build a reliable, independently maintained data collection specifically for word-puzzle games.

As our own datasets become available, temporary third-party data will be progressively replaced.
